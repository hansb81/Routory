# AI analysis notice

> CLAUDE.md에서 이동된 상세 내용. 이 영역을 작업하기 전에 먼저 읽을 것.

- **AI analysis notice (`aiNotice.js`)**: a separate, one-time-only disclosure — distinct from the permission prompts above — that a selected photo/file may be sent to an AI analysis service. Shown by `flight.js#openForm` (only on the *new*-flight path, right as the "선택" screen with the OCR card renders — never on edit, which has no photo step) and `tripImport.js#open` (every time that modal opens). Both just call `aiNotice.showOnce()`; the module itself decides whether anything actually happens. One shared message and one shared "seen" flag cover both features — not two separate notices — because the disclosure is about this app using AI analysis at all, not about either feature specifically, so confirming it from either screen suppresses it on the other too. The "seen" flag is `localStorage["triplog.aiNotice.seen.<auth.getUserId()>"]`, deliberately keyed per account (requested explicitly) rather than one global flag, the same spirit as `storage.js` treating a different signed-in user as needing its own state; if the user id can't be read, it falls back to an unscoped key rather than failing to remember at all. Reuses the same `.modal-overlay`/`.modal-confirm` markup as the permission prompts and `tripShell.js`'s exit-confirm (no new CSS) and relies on the same "later-appended element wins the paint order at equal z-index" stacking behavior to sit above whichever feature modal is already open underneath it. Unlike most modals in this app, it has **no** backdrop-click or Escape dismissal — only the "확인했습니다" button closes it, a deliberate choice so a one-time disclosure can't be skipped by accident.
